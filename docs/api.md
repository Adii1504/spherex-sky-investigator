# API v1

All paths below are under `/api/v1`. Errors have `code`, `message`, and optional `details`; no adapter exception strings are exposed. FastAPI request validation returns 422. Missing capabilities return 503; queue/cache exhaustion returns 503; unavailable upstream search results return 502 and search execution deadline returns 504. A failed asynchronous job is returned by GET with HTTP 200 and a structured `error`.

1. `GET /health` returns `status: ok` and capability states for archive_access, image_processing, motion_verification.
2. `POST /observations/search` with `{"ra_deg":12,"dec_deg":-5,"fov_arcmin":2,"start_utc":"2025-01-01T00:00:00Z","end_utc":"2025-12-31T23:59:59Z"}` returns `search_id`, `observations`, `coverage_summary`, `warnings`. Dates are optional, timezone-aware; offsets are accepted as instants. Coordinates must be finite. Empty coverage is a successful empty observation list.
3. `POST /sequences` with `{"search_id":"<id>","observation_ids":["<observation-id>"],"ra_deg":12,"dec_deg":-5,"fov_arcmin":2}` returns 202 `{"job_id":"<id>"}`. Field must exactly match the search so cached observations cannot be reused for an unrelated sky position.
4. `GET /jobs/<id>` returns `job_id`, queued/running/succeeded/failed `status`, nullable `progress`, `result`, `error`. Poll approximately once per second; stop on terminal state. Sequence result includes chronologically ordered previews with observation metadata and preview_url, processing_version, processing_settings, shared_display_settings, measurements, warnings. Partial cutout/preview failures are warnings; zero usable previews fails the job. PNG URLs are opaque, same-origin `/api/v1/previews/<id>` paths; no local paths are accepted or exposed.
5. `POST /investigations` takes the same selection plus optional `sequence_job_id`. Returns 201 `{"investigation_id":"<id>"}`. A sequence reference must be successful and match the exact search and selected IDs. Without it, evidence explicitly warns no processed sequence is attached.
6. `POST /investigations/<id>/verify` with `{"training_observation_ids":["<id-a>"],"reserved_observation_ids":["<id-b>"]}` returns 202 job_id. IDs must belong to the saved selection. Both sets must be nonempty. Duplicate observation IDs or canonical exposure identities anywhere in the combined sets return 422 `exposure_overlap`. Products/detectors from the same exposure cannot evade this check. No confidence score is generated. Adapter assumptions, measurements, limitations and insufficient_evidence outcome are retained.
7. `GET /investigations/<id>/evidence` returns JSON with schema_version `1.0`, investigation_id, selection, observations/provenance, processing (nullable), warnings, and verification job snapshots including results when complete. Save this response as the evidence artifact. Poll verification to completion before final export.

The browser supplies IDs only, never download URLs. Metadata is scientific export data: adapters must not include secrets, filesystem references, or signed download links. Defense-in-depth export filtering strips sensitive key names, common local paths, and URL credentials/query/fragment; arbitrary unlabelled secrets cannot be detected automatically. Provenance should contain stable public archive URLs and product identity.
