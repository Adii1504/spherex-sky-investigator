The Astronomical Dilemma
  • Coarse Native Resolution: At 6.2 arcsec/pixel, nearby brown dwarfs and fast asteroids blend with background noise. Simple thresholding fails completely.
  • Saturated Cores on Bright Stars: Stars with V < 11 saturate the central detector pixel, appearing as NaNs in Level 2 flux maps.
  • Linear Variable Filters (LVF): Central wavelength varies continuously across each focal plane. Images from different passes cannot be naively differenced.
  • Blind Machine Learning Hallucinations: Black-box ML models produce false-positive discoveries on survey artifacts with zero verifiable physical basis.
The WhyLab Solution
  • WCS Tangent Reprojection: Standardizes disparate cutouts on a unified North-up / East-left celestial TAN grid with spherical flux conservation.
  • 2D Gaussian PSF Wing Centroiding: Centroids bright stars from surrounding unmasked wings, overcoming saturated core NaNs to reach 0.12'' accuracy.
  • Digital Difference Dipole Detection: Pixel-by-pixel subtraction (B - A) on shared dynamic range reveals textbook signed dipoles confirming physical motion.
  • Held-Out Hypothesis Testing: Fits linear kinematics on training epochs; strictly evaluates a reserved epoch without data leakage. Science over hype!

8 Core Scientific Image Processing Algorithms Built From Scratch
1. WCS Reprojection [reproject_interp]:

Spherical flux-conserving coordinate transformations mapping detector cutouts to common North-up / East-left TAN grid.

2. Saturated Wing Fitting [curve_fit]:

Recovers accurate centroids for bright stars with saturated NaN cores from surrounding unmasked 2D Gaussian wings.

3. Digital Differencing [B - A]:

Signed array subtraction on shared baseline canceling stationary stars and revealing positive/negative motion dipoles.

4. Shared Dynamic Stretch [p1 - p99]:

Global multi-epoch percentile contrast normalization preventing brightness flicker during blinking and differencing.

5. Quality Bitmasking [FLAGS & MASK]:

Distinguishes fatal defects (cosmic rays, dead pixels) from informational tags (catalog match), preventing false pixel rejection.

6. Sub-Pixel Centroiding [Levenberg-Marquardt]:

Achieves 0.12'' astrometric accuracy from coarse 6.2'' pixels using flux-weighted moments and 2D Gaussian fitting.

7. 3-Band RGB Synthesis [Lupton/Asinh]:

ViewSpace false-color synthesis: D5-D6 (Red, dust), D3-D4 (Green, ices), D1-D2 (Blue, stellar continuum).

8. Temporal Blinking Engine [PIL Frame-Buffer]:

Adaptive palette quantization and dwell-controlled animation generator powering the interactive comparator.

Scientific Detection & Kinematic Signatures
Digital Image Differencing: The Signed Dipole Signature
Physical Principle of the Signed Dipole
  • Pixel-by-Pixel Subtraction: For aligned epochs A and B, difference image D = B - A is computed on a symmetric diverging scale centered on 0.0 (Coolwarm).
  • Cancellation of Fixed Stars: Astrometrically stationary field stars cancel out completely to zero (residual flux within background noise).
  • The Signed Dipole Signature: A moving object leaves a negative deficit (dark blue pit) at its original position A, and a positive excess (bright red peak) at its new position B.
  • Barnard's Star Case Study: SPHEREx observations spanning 2025 to 2026 clearly capture its real celestial motion (+9.0'' Dec displacement), creating an unambiguous dipole signature (-8.97 to +6.05 MJy/sr) matching Gaia DR3 truth!

Astrometric Kinematics & Rigorous Evaluation
Held-Out Hypothesis Testing: Science Over Blind Machine Learning
The Scientific Hypothesis Protocol
  • Training vs Reserved Split: Constant-velocity linear model fits (vx, vy) exclusively on training epochs. The evaluation epoch is strictly reserved.
  • Zero Data Leakage: The held-out epoch's position is predicted at its exact observation timestamp without fitting to its centroid or flux.
  • Astrometric Floor: Evaluates residuals against detector uncertainty floor (sigma_eval = sqrt(sigma_raw^2 + 0.5^2)).
  • MOTION_SUPPORTED: Object moved > 2*sigma beyond stationary noise, and motion prediction error < 2.5*sigma.
  • STATIONARY_PLAUSIBLE: Reserved offset <= 2*sigma. Consistent with null hypothesis; data does not require motion.
  • INSUFFICIENT_EVIDENCE: Discrepant motion or excessive residual. A valid scientific safeguard!

Smart Result Reuse

Identical in-flight requests share computation work via bounded session queues. Completed sequences and previews are cached on disk and reused instantly if inputs remain unchanged.

Synchronous adapters run in bounded thread pools, completely isolating CPU-heavy numpy calculations from async event loops. Persistent HTTPS connection pooling caps active downloads.

Automatic browser reconnection polling during temporary outages. Partial sequence recoveries retain valid observations if one cutout fails. Zero-SSRF security prevents unauthorized requests.
