# SPHEREx WhyLab frontend

The explorer header includes an adaptation of the supplied `Starfield.jsx` and
standalone starfield visual reference, using lazy-loaded Three.js. Its particles
are labelled decorative simulations, not catalogue objects. Pause/resume and
reduced-motion support are included; the effect falls back to a static background
without WebGL2. Pointer parallax is limited to the header, with no global wheel
handler affecting the astronomical map or page scrolling.

A single-page, image-first investigation workspace built with React 19 and Vite 6.
The dark shell, contextual sidebar, circular image controls and observation
timeline come from teammate commit `d998e4f2968b701caef2e14b382d96ee49e4ae23`,
integrated into this backend checkout. No ViewSpace
branding, imagery, text or code is included.

## Run locally — Windows PowerShell

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

Open the Local URL printed by Vite, normally `http://127.0.0.1:5173`.
`npm.cmd` avoids the PowerShell execution-policy restriction on `npm.ps1`.
This setup and its Node test loader were validated on Node **26.13.1**, npm
**11.20.0**. Runtime dependencies include React, React DOM and Aladin Lite; the added
development dependency is **happy-dom**, for React interaction tests without a
browser. Tests use Node's `module.registerHooks` and the esbuild supplied by Vite.

The Python backend runs as a separate process from this repository's root:
`.\.venv\Scripts\python -m whylab` in PowerShell. Frontend development commands
do not start the backend.
Alternatively, run `npm.cmd run build` here and open `http://127.0.0.1:8000/`:
the backend serves `frontend/dist` and `/api` from the same origin. After rebuilding,
hard-refresh the browser to load the new assets.

## Try the complete viewer without a backend

1. Open **Sky regions**, explicitly choose **Development fixtures**.
2. Enter valid numeric inputs, e.g. RA `12`, Dec `-5`, FOV `2` for UI testing.
   These values are not verified coordinates for a named target.
3. Search, select the observations in the drawer, then **Generate sequence**.
4. Step, scrub, play/pause, change speed, zoom, pan or inspect the navigator.
5. Use **Compare** for A/B blink and independent side-by-side views.
6. Try the No observations, Archive error, Partial sequence, Sequence job error,
   and Image loading error fixture scenarios from Sky regions.

Fixture mode is always labelled **Development fixture — not real SPHEREx data**.
Its three PNGs are geometric calibration charts labelled DEMO, generated by
`node scripts/generate-fixtures.mjs`. All dates, science values and identifiers
are fictional. No scientific verification or downloadable evidence is fabricated;
those actions require a live investigation. The image-error fixture intentionally
keeps one URL missing so Retry image can be exercised; choose Success and rebuild
to recover. Live errors never enable fixtures automatically.

## Live backend connection

Default `VITE_API_BASE` is empty. The development server proxies `/api` to
`http://127.0.0.1:8000`, avoiding cross-origin access locally. Use the compact
header diagnostics to retry the connection and inspect each capability. An
unavailable backend leaves the workspace usable without claiming data is loaded.

For a separate backend, copy `.env.example` to `.env.local`, set
`VITE_API_BASE=https://your-backend-origin` with no `/api/v1` suffix, then restart
Vite. The backend owner must allow the exact frontend origin through
`WHYLAB_CORS_ORIGINS`. A production build needs a same-origin `/api` reverse proxy
or the correct `VITE_API_BASE` at build time. `vite preview` has no API proxy.

Actual backend contract: `origin/feature/backend` at
`c68896856d29b3a785088936280e1c95f0875e7b`.

- `/api/v1/health` reports independent archive, processing and verification states.
- Search returns `search_id`, `observations`, `coverage_summary`, `warnings`.
- Sequence submission uses the exact successful search coordinates and selected
  IDs; a job's `previews[]` carry complete observations, PNG URLs and metadata.
- Polling is approximately one second, stops at terminal states or cancellation,
  and accepts `progress: null`. Fixture jobs exercise the same poll loop locally.
- Investigation creation uses the searched selection plus `sequence_job_id`.
- Verification sends training/reserved arrays only. Groups must use unique,
  disjoint canonical exposures; the UI retains the built-in adapter policy of
  three training exposures and one reserved exposure.
- Outcomes are `supported`, `not_supported`, `insufficient_evidence`. Evidence is
  fetched from the real endpoint and downloaded without altering scientific values.
- API errors are flat `{code, message, details?}`. Non-JSON proxy failures and
  network failures also have readable recovery states.

The frontend matches default backend limits: FOV `(0,30]` arcminutes and at most
100 selected observations. If deployment changes those limits, update
`MAX_FOV_ARCMIN` in `src/search.js` and `MAX_OBSERVATIONS` in `src/workflow.js`
(plus the selection drawer's guard). Health does not expose these limits.

## Behavior and scientific boundaries

- New searches, reset and mode/scenario changes abort old requests, discard stale
  results, clear temporary IDs and stop playback. Clear selection invalidates the
  old sequence. Stop waiting stops browser polling; server work may continue.
- Playback loops in returned chronological order. Manual scrub/step pauses it.
  Entering comparison pauses playback; blink has a separate, mutually exclusive
  timer and its actual displayed image drives the metadata/date labels.
- Zoom is limited to 1–6×, preserves image ratio and clamps pan. Navigator
  rectangles describe PNG positions, never sky coordinates. Zoom adds no detail.
  Arrow keys pan, +/- zoom, 0 resets; the display grid is explicitly a UI aid.
- Side-by-side panes pan/zoom independently. No scientific alignment or wavelength
  compatibility is inferred by the UI. Backend warnings remain visible.
- Scientific Difference stays unavailable: the API has no dedicated difference
  preview URL. Browser PNG subtraction and pixel-to-sky source selection are absent.
- All five presets remain disabled pending verified coordinates. The investigation
  center is the searched field; change it by running a new search.
- Health availability does not establish scientific validity. The built-in
  exploratory verifier currently returns `insufficient_evidence`, even when it
  can report fit measurements. No confidence percentage or discovery claim is added.
- Search sessions, preview mappings, jobs and investigations can expire or disappear
  after server restart. A 404 requires a new search/sequence/investigation.

## Structure

```text
src/
  App.jsx                         Workflow state, request ownership, navigation
  main.jsx                        React entry point
  api.js                          Shared HTTP client, polling, preview URL handling
  search.js                       Existing validation and search/health contract
  workflow.js                     Selection, sequence/investigation/evidence services
  viewer.js                       Pure zoom/pan/navigator geometry
  hooks/useHealth.js              Capability loading and retry
  components/
    AppHeader.jsx                 Navigation and compact diagnostics
    SearchPanel.jsx               Collapsible search and explicit fixture control
    SearchResults.jsx             Selectable observation drawer/date range
    SkyViewer.jsx                 Image loading, retry, zoom/pan/fullscreen/blink
    Timeline.jsx                  Stepping, scrubber, playback and speed
    ContextPanel.jsx              Details, Compare, Investigate and Evidence
    MetadataDetails.jsx           Scientific metadata and provenance
  fixtures/developmentData.js     Fictional responses and queued job lifecycle
  data/targetPresets.js            Names awaiting verified coordinates
  style.css                       Dark responsive shell and focus styling
  *.test.js                       API, workflow, geometry and React DOM tests
public/fixtures/                   Three labelled synthetic calibration PNGs
scripts/register-jsx.mjs           JSX transform for Node tests via existing esbuild
scripts/generate-fixtures.mjs      Reproducible test chart generation
```

## Validation

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

`npm test` covers API shapes, errors, cancellation, selection/exposure rules,
job lifecycles, geometry and real React interactions in happy-dom. Synthetic HTTP
stubs also exercise save, verification and evidence export. Native fullscreen is
mocked in tests. These tests do not prove visual layout, real touch/browser behavior
or live astronomical validity. Use the checks below for final browser review:

- Laptop and narrow/mobile layout, collapsed sidebar and drawers, keyboard focus.
- Fixture search → select → generate → play, including error and partial states.
- Image retry, wheel/pinch zoom, drag/keyboard pan, navigator rectangle, native
  fullscreen and Escape; verify no console errors.
- With configured real adapters: covered field, preview/provenance review,
  independent verification and evidence export. No live data downloads run in tests.
